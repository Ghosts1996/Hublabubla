# Vibe

Vibe — красивый MVP веб-плеера для личной музыки.

## Возможности

- адаптивный интерфейс для desktop и mobile;
- обзор, поиск, моя музыка, любимые треки и очередь;
- воспроизведение, прогресс, громкость, shuffle/repeat;
- сохранение любимых треков в `localStorage`;
- добавление локальных аудиофайлов;
- добавление прямой HTTPS-ссылки на аудиофайл;
- массовый импорт ссылок на альбомы и плейлисты VK, Яндекс Музыки и Spotify;
- массовое добавление импортированных позиций в избранное;
- импорт CSV с колонками `title, artist, album, url`;
- сохранение импортированной коллекции в браузере;
- поиск текстов и метаданных через Genius Search;
- подготовленная точка интеграции Musixmatch/Genius API через backend;
- безопасный каталог поддерживаемых источников вместо встраивания загрузчиков в браузер.

## Интеграции и ограничения

Ссылки на Musixmatch и Genius используются для текстов и метаданных. API-ключи должны храниться только на backend в переменных окружения.

`yt-dlp` и `spotDL` нельзя подключать в frontend: это серверные инструменты, а их применение к защищённому или чужому контенту может нарушать права и правила источника. Vibe принимает локальные файлы, разрешённые прямые аудио-ссылки и метаданные. DRM, обход ограничений, массовое скачивание чужой музыки и удаление ограничений источников не поддерживаются.

## Запуск

Скачай репозиторий кнопкой **Code → Download ZIP**, распакуй архив и открой `index.html` двойным кликом. Установка Node.js, Python и зависимостей не нужна.

Для локальных файлов некоторые браузеры могут ограничивать работу при открытии через `file://`. В таком случае запусти в папке проекта:

```bash
python3 -m http.server 8080
```

После этого открой `http://localhost:8080`.

## Что работает сразу

- оригинальные встроенные демо-треки без внешних аудиоссылок;
- красивый адаптивный интерфейс для телефона и компьютера;
- проигрывание локальных файлов и разрешённых прямых HTTPS-аудиоссылок;
- избранное, очередь, поиск, shuffle/repeat, громкость и прогресс;
- импорт CSV и экспорт коллекции;
- сохранение метаданных и избранного в `localStorage`;
- поиск текстов через Genius в новой вкладке.

## Важно

Файлы, выбранные с устройства, не загружаются на сервер и доступны только в текущей вкладке. Ссылки Spotify, VK и Яндекс Музыки импортируются как метаданные, но не превращаются в скачивание или обход ограничений сервиса. Для этого нужны официальные API, права и backend.

## Android APK

Проект содержит Capacitor-обёртку для Android. После push в ветку `feat/download-and-play` GitHub Actions автоматически собирает APK.

1. Открой вкладку **Actions** на GitHub.
2. Выбери workflow **Android APK** и дождись статуса ✅.
3. Открой завершённый запуск, прокрути до **Artifacts** и скачай `Vibe-Music-debug-apk`.
4. Распакуй ZIP и установи `app-debug.apk` на Android. При необходимости разреши установку из неизвестного источника.

Это debug APK для личного использования. Для публикации в Google Play нужен подписанный release APK/AAB с собственным ключом подписи.

## Важно о ссылках на музыку

Для проигрывания через URL нужна именно прямая ссылка на аудиофайл с разрешённым CORS, а не ссылка на страницу YouTube, VK, Spotify или другого сервиса. Подключать чужие каталоги и скачивать защищённую авторским правом музыку можно только через официальные API и лицензии.

В production-версии стоит добавить backend, авторизацию, облачное хранилище, нормализацию метаданных, плейлисты и официальные музыкальные интеграции.
